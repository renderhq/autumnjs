# @autumnjs/create

CLI to create new Autumn.js applications with modern templates.

## Usage

```bash
# Using npm
npm create @autumnjs/app

# Using pnpm
pnpm create @autumnjs/app

# Using yarn
yarn create @autumnjs/app
```

## Templates

- **default**: Basic Autumn.js with TypeScript and JSX.
- **tailwind**: Default template with Tailwind CSS integrated.
